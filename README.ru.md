# onec-bitrix-observability-pack

**onec-bitrix-observability-pack** — это открытый набор инструментов для построения системы наблюдаемости (observability) за стеком **1С:Предприятие** + **1C-Bitrix** + **СУБД**.

## Состав пакета

1.  **Экспортёры (Exporters):**
    *   `onec_exporter`: Сбор метрик с кластера 1С (сессии, блокировки, фоновые задания).
    *   `bitrix_exporter`: Сбор метрик производительности Bitrix (PHP-FPM, Nginx, специфичные метрики модуля).
    *   Конфигурации для стандартных DB-экспортёров (Postgres, MySQL, MSSQL).

2.  **Дашборды Grafana:**
    *   `Overview`: Светофор для руководства (доступность, ключевые KPI).
    *   `Admin/DBA`: Детальные графики по ресурсам, блокировкам, медленным запросам.
    *   `Deep Dive`: Инструменты для расследования инцидентов.

3.  **Алертинг:**
    *   Готовые правила Prometheus (Alert Rules) на основе методологии Four Golden Signals (Latency, Traffic, Errors, Saturation).

4.  **AI-Assistant:**
    *   Модуль анализа временных рядов для выявления аномалий.
    *   Генерация рекомендаций на естественном языке (без отправки чувствительных данных во внешние облака по умолчанию).

## Быстрый старт

Требуется `docker` и `docker-compose`.

1.  Склонируйте репозиторий.
2.  Изучите `docker-compose.example.yml`.
3.  Настройте параметры подключения к вашим серверам в конфигах `exporters/`.
4.  Запустите: `docker-compose up -d`.
